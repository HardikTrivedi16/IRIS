# Scheme catalogue — intentionally empty

Verified scheme records go here, in the format defined in
`docs/SCHEME_CATALOGUE_INPUT_REQUIREMENTS.md`:

    schemes/SCH-####.yaml
    scheme-conditions/SCHC-####.yaml

Until ACTIVE + VERIFIED records exist, IRIS shows
**SCHEME CATALOGUE AWAITING VERIFIED DATA** and produces no eligibility
results.

Do not add placeholder, illustrative or "sample" schemes here. Synthetic test
fixtures live in `tests/fixtures/scheme-data/` and use `SCH-9###` ids.
